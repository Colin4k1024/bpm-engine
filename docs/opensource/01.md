### ✨ “Why another BPM engine?”（关键说服点）

你可以直接用这个逻辑（非常有说服力）：

- Most BPM engines optimize for **features**
- This engine optimizes for **correctness**
- Token state is persisted and replayable
- Every execution path is auditable
- Concurrency and crash safety are first-class

### Worker 示例（非常重要）

```rust

    ctx.complete().await
}
```

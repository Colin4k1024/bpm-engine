# BPM Engine 中文文档支持 — 需求简报

## 1. 背景

`bpm-engine` 项目目前文档以英文为主（README, architecture.md 等），缺少中文使用文档和设计文档，影响中文用户和开发者理解与上手效率。

**项目性质**: 开源 Rust BPM 引擎

## 2. 目标与优先级

| 优先级 | 目标 |
|--------|------|
| **P0** | 中文 README 快速开始指南 |
| **P0** | 中文 API 文档（基于 api-contract.md） |
| **P1** | 中文设计文档（架构、设计决策） |
| **P2** | 中文 BPMN 用户指南 |
| **P2** | 示例流程中文说明 |

**成功标准**：
- 中文用户能在 5 分钟内通过中文文档启动并运行第一个流程
- 中文开发者能理解核心架构和设计决策

## 3. 关键约束

- **只做文档，不实现代码**
- 文档需与英文版保持同步更新
- 中文翻译需准确，避免歧义

## 4. 参与角色清单

| 角色 | 主责 |
|------|------|
| `tech-lead` | 统筹文档范围、收口结论 |
| `architect` | 技术文档审核 |
| `doc-writer` | 中文翻译与文档编写 |

## 5. 待确认项

| # | 问题 | 状态 |
|---|------|------|
| 1 | 中文 README 是否需要覆盖全部英文 README 内容？ | ✅ 全部覆盖 |
| 2 | 文档同步机制：如何确保中英文同步更新？ | ✅ 同步机制（gitbook 或 CI 验证） |
| 3 | API 文档是否需要完整翻译还是仅关键部分？ | ✅ 仅关键部分 |

## 6. 企业治理（不适用）

本项目为开源 BPM 引擎，不涉及企业内控约束。
